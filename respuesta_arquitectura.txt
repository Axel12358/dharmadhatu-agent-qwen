## ARQUITECTURA PROPUESTA

El sistema se compone de dos componentes principales: `search_groups` para [K
buscar grupos y `search_events` para buscar eventos directamente. Cada comp[4D[K
componente tiene sus propias funcionalidades, flujos de trabajo y configura[9D[K
configuraciones.

### ESTRUCTURA DE CONFIGURACIONES (JSON)

**config_search_groups.json**
```json
{
    "base_url": "https://example.com/groups",
    "keywords": ["rock", "pop", "country"],
    "types_of_events": ["festival", "outdoor", "gathering"]
}
```

**config_search_events.json**
```json
{
    "base_url": "https://example.com/events",
    "keywords": ["rock", "pop", "country"],
    "types_of_events": ["festival", "outdoor", "gathering"]
}
```

### ESTRUCTURA DE MÓDULOS (nombres y responsabilidades)

1. **main.py** - Punto de entrada principal que ejecuta los flujos.
2. **search_groups.py** - Maneja el flujo de búsqueda de grupos.
3. **search_events.py** - Maneja el flujo de búsqueda directa de eventos.
4. **utils.py** - Utilidades comunes para navegación y procesamiento.

#### utils.py
```python
import requests
from bs4 import BeautifulSoup

async def fetch_page(url):
    response = await requests.get(url)
    return response.text

def parse_html(html_content, selector):
    soup = BeautifulSoup(html_content, 'html.parser')
    return soup.select(selector)
```
